# cgr-control-previo-equipo

Catálogo de reglas de control previo aplicadas a libramientos de pago.
Repositorio compartido del curso de Git · Contraloría General de la República.

Alcance: reglas de control previo, parámetros de revisión y consultas de apoyo.

## Cómo contribuir

1. Crea una rama `feature/rNN-descripcion` desde `main`.
2. Agrega tu regla en `reglas/detalle/R-NN.md`.
3. Abre un pull request hacia `main` y asigna a tu pareja como revisor.
4. `main` está protegida: todo cambio entra por pull request aprobado.
